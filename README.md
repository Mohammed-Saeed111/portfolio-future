Portfolio Future - Client Project for Yard

This is a portfolio website project developed for Future using React and deployed on Vercel. The website showcases a collection of projects and professional achievements,
designed to demonstrate the client's expertise and work experience.

Features

Modern Design: A clean, modern design with a user-friendly interface.

Responsive: Fully responsive layout to ensure the website looks great on all devices (desktop, tablet, mobile).

Project Showcase: Displays a variety of the client's key projects and portfolio work.

Smooth Navigation: Easy-to-use navigation to help users quickly find relevant sections.

Contact Form: Allows visitors to get in touch with the client via a simple contact form.

Technologies Used
React.js: Front-end library to build the interactive user interface.

CSS / Styled Components: Custom styling for a modern and professional look.

Vercel: Hosting and deployment platform to serve the live website.
